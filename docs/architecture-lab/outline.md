# Agentic Architecture Lab 课程大纲

受众为已理解 Agent Tool Calling 与基本工作流的软件工程师、架构师和技术负责人。课程以质量属性驱动设计为主线，Booking Precheck 只是贯穿的合成教学案例。

## A：业务证据与系统边界

逻辑页 1–7。建立业务边界，理解三份输入单证、事实归一化、规则判断与证据回溯，完成一个冲突或缺件案例的推演。

## B：基线与公平评测

逻辑页 8–17。区分 Dataset、Task、Trace、Evaluator 和 Experiment；理解答案隔离、统一接口、环境检查以及质量、安全与效率指标。当前模块讲解实验设计，不附带运行 Harness。

## C：当前架构及其压力

逻辑页 18–22。观察 Single-Agent 循环，区分 Messages 与业务状态，识别结构的优点、代价与压力。工具名是参考实现，不构成强制依赖。

## D：质量属性驱动设计

逻辑页 23–29。把抽象质量愿望转为可测试场景，排序驱动因素，明确权衡和预期测量。

## E：模式、职责与设计决策

逻辑页 30–36。从 Driver 和 Tactic 推导职责、Pattern 与接口，比较候选方案并写下 ADR、代价及否决条件。

## F：上下文与协作契约

逻辑页 37–43。设计 AgentTask、AgentResult、Shared Case State 和 Reducer。明确最小上下文、共享状态所有权以及关键 Worker 失败时的安全行为。

## G：最小实现与 AI 辅助

逻辑页 44–47。让 AI 辅助代码实现，但由团队负责边界与验收。以契约闭环、单案例和冻结案例集作为实现门槛。实际编码实验需另行准备代码环境。

## H：比较、解释与决定

逻辑页 48–54。比较同一案例集的结果及代价，分析坏案例，提出 Adopt、Adapt 或 Reject。没有测量时只能给出设计建议与验证计划。

## 页数与教学安排

播放器包含 71 个物理页面，保留连续逻辑页及字母插页，Optional Detail 可按需要显示或隐藏。原项目中写 69 页的旧大纲不再作为本模块页数依据。本课程不绑定某一天或固定时间表；讲师根据学员基础和是否自备运行环境安排节奏。
